# Alarm Clock Project

## Objective
To create a simple alarm clock using Python.

## Features
- Set alarm time
- Checks current time continuously
- Gives alert when the set time is reached

## Technologies Used
- Python
- Time Module
- Winsound Module

## How to Run
1. Open the project in VS Code.
2. Run alarm_clock.py.
3. Enter the alarm time in HH:MM:SS format.
